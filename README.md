# Daily Ideas

Jason's personal micro-learning app: 5-minute book idea cards, quizzes, streaks, flashcard review, read-aloud and a daily top-news digest.

- `books.js`: book cards and quizzes (original summaries)
- `news.json`: today's news digest, updated each morning by a Claude scheduled task
- Progress syncs to the private repo `News_brief_log` (file `progress.json`) using a GitHub key stored only on each device.
